## 內文
各位同學好

今天專欄幫各位整理有關土地稅重購退稅之比較：



| 適用條件 | 土地增值稅 | 房地合一稅 |
| --- | --- | --- |
| 適用條件 |  | 土地增值稅 |
| 法源依據 |  | 土地稅法第37條 |
| 標的物條件 | 對象 | 自用住宅用地 |
| 建物產權 | 須為本人或其配偶、直系親屬所有 | 須為本人或其配偶所有 |
| 設籍 | 土地所有權人或其配偶、直系親屬於該地辦竣戶籍登記 | 個人或其配偶、未成年子女辦竣戶籍登記並居住 |
| 狀態 | 出售前一年無出租、營業 | 出售前一年無出租、<br>供營業或執行業務（申報要點似未明確規定，<br>按財政部公布內容） |
| 重購名義(新舊所有權人) |  | 土地所有權人(須為同一所有權人) |
| 重購時間 |  | 自完成出售移轉登記之日起算二年內重購或先購後售 |
| 重購面積(新房地) |  | 都市土地未超過3公畝非都市土地未超過7公畝(舊房地<br>不限) |
| 退稅額度 |  | 新購土地地價超過原出售土地地價，<br>扣除繳納土地增值稅後之餘額者，<br>得向主管稽徵機關申請就其已納土地增值稅額內，<br>退還其不足支付新購土地地價之數額（差額退） |
| 退稅時效 |  | 10年（102.5.24後） |
| 追繳情形 |  | 重購後五年內改作其他用途或再行移轉時，<br>應追繳原退還稅額 |
| 請求次數 |  | 不限 |
